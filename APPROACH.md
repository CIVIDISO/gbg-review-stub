I built a concrete review-syndication stub for Gangnam Beauty Guide: a zero-dependency Node pipeline that normalizes synthetic Korean/English aesthetics reviews, collapses clinic name variants into a stable clinic_key, fingerprints cross-source copies with a content_hash, scores trust from verified-procedure / verified-surgeon flags plus a source prior, merges duplicates, and renders clinic cards on a static demo page. I chose clinic_key = slug(canonicalize(name))|slug(city) because name+city is the smallest join key that works before a clinic master DB exists, and a tiny alias table stands in for entity resolution on noisy forms like Hangul clinic names versus punctuated English brand spellings. The content hash is author + date + normalized body (preferring the English body when present) so Naver Cafe posts and clinic-site reposts of the same story collide without needing fuzzy similarity in this stub. Trust is 0.45·source_weight + 0.30·verified_procedure + 0.25·verified_surgeon because English medical-tourism buyers care most that the procedure and surgeon are real, while still discounting owned clinic pages relative to cafe word-of-mouth. On merge I keep the highest trust score, break ties with the earliest review date, and OR verification flags across copies so a signal present on only one source is never lost. The runnable artifact is deliberately deployable as static files (public/index.html + data.json) with node pipeline.mjs as the only build step. Sample fixtures intentionally mix KO placeholders, EN text, and near-duplicate syndication pairs across naver_cafe and clinic_site so the dedupe and trust paths are observable in the demo. In production I would replace the alias table with a clinic master linked to licenses and addresses, add embedding or MinHash near-dupe detection for paraphrases, plug in a real KO→EN translation queue with human review for high-traffic clinics, and attach anti-fraud / rate-limit signals before trust scoring. I would also separate ingestion per source behind adapters, store raw and normalized rows immutably, and expose trust badges as first-class UI for buyers comparing RealSelf-style listings against Korean forum reality.
